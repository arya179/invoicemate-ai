# InvoiceMate AI 🧾

> **AI-Powered Invoice & Expense Management for Freelancers and Small Businesses**  
> Built for the **Hacktoberfest Week 2: Side Hustle Edition**.

InvoiceMate AI simplifies financial record-keeping for independent contractors, solopreneurs, and small business owners. It runs **100% locally on your machine** using Ollama and the lightweight `gemma:2b` model—keeping your financial data, client names, and billing records strictly private without incurring cloud API costs.

---

## ✨ Features

- 📊 **Polished Business Dashboard**: Real-time expense metrics, spending by category chart, recent transactions, and average transaction metrics.
- 📄 **Multi-Format Ingestion**: Supports PDF documents, scanned receipts, and image invoices (`.png`, `.jpg`, `.jpeg`).
- 🔍 **Hybrid Text Extraction**: 
  - Direct digital text extraction with **PyMuPDF**.
  - Automatic fallback to **Tesseract OCR** for scanned documents or image receipts.
- 🤖 **Local AI Structuring (`gemma:2b`)**:
  - Extracts Vendor, Invoice Number, Invoice Date, Subtotal, Tax, Total, Currency, and Expense Category.
  - Robust regex fallback heuristics if the document is irregular or AI outputs need reinforcement.
- 🛡️ **Human-in-the-Loop Review**:
  - An editable review form allows verifying and adjusting fields before any data is saved.
  - Zero accidental or unverified saves to the database.
- 🗄️ **Persistent Storage & Search**:
  - SQLite database using parameterized queries to protect against SQL injection.
  - Live filtering by category and full-text keyword search across vendor, invoice number, and notes.
- 📥 **CSV Export**: Export clean expense ledgers for accounting, tax filing, or accountant review.
- 🧪 **Built-in Synthetic Invoice Generator**: Generate realistic, customizable test invoices on demand for quick testing.

## 🛠️ Tech Stack & Requirements

- **OS**: Ubuntu Linux (or any Linux/macOS/Windows environment)
- **Language**: Python 3.10+
- **Frontend / UI**: [Streamlit](https://streamlit.io/)
- **Local AI Engine**: [Ollama](https://ollama.ai/) with `gemma:2b`
- **PDF Extraction**: [PyMuPDF](https://pymupdf.readthedocs.io/)
- **OCR Engine**: Tesseract OCR via `pytesseract` and `Pillow`
- **Database**: SQLite3
- **Data Manipulation**: Pandas

## 🚀 Quickstart Guide

### 1. Ensure Ollama & Model are Running
Verify that Ollama is installed and running with `gemma:2b`:
```bash
# Check if ollama service is active
ollama list

# If gemma:2b is not installed:
ollama pull gemma:2b

# Make sure the daemon is running:
ollama serve
```

### 2. Verify System Dependencies (Tesseract OCR)
```bash
# On Ubuntu / Debian:
sudo apt-get update && sudo apt-get install -y tesseract-ocr
```

### 3. Activate Environment & Install Python Dependencies
```bash
cd /home/bisagn/hackoberfest/week_2

# Using the virtual environment
source .venv/bin/activate

# Install requirements
pip install -r requirements.txt
```

### 4. Launch InvoiceMate AI
Run the Streamlit application:
```bash
streamlit run app.py
```
Open your browser at `http://localhost:8501`.

## 📋 Manual Testing Checklist

1. **System Health Check**:
   - Check the left sidebar to confirm the green status indicator: `🟢 Local AI: Gemma 2B Ready`.
2. **Generate a Sample Invoice**:
   - Go to `🧪 Sample Generator`.
   - Select `Cloud Hosting (Digital Ocean / AWS)`.
   - Click `Download ACT-2026-4401.pdf`.
3. **Upload & AI Extraction**:
   - Navigate to `📤 Upload & Parse`.
   - Upload the downloaded sample PDF (or an image invoice).
   - Verify the document preview loads on the left.
   - Click `Process Invoice with Gemma 2B`.
   - Inspect the extracted vendor, invoice number, subtotal, tax, and total.
4. **Review & Confirm**:
   - Modify any field in the review form if needed (e.g. add notes).
   - Click `Save Confirmed Invoice`.
5. **Dashboard & All Invoices**:
   - Navigate to `📊 Dashboard` to confirm metrics updated and the category chart populated.
   - Navigate to `📑 All Invoices` to search by vendor or export the records as a CSV.

## 🔒 Security & Privacy Notice

- **No Data Leaves Your Computer**: All LLM inference and OCR are executed entirely locally. No third-party APIs or cloud endpoints are invoked.
- **Verification Disclaimer**: Extracted amounts are estimations generated by a compact language model. They do not substitute professional accountant or tax advice. Users must review all extracted values before saving.
